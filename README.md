# Mateus Marques Rosa — Advocacia Criminal

Site institucional em Next.js baseado no layout desktop do Figma, com adaptação responsiva para dispositivos móveis.

## Executar localmente

```bash
npm install
npm run dev
```

Contato, endereço de atendimento e textos de serviço vieram do layout do Figma e do briefing enviado pelo Tally. Os botões de contato abrem o WhatsApp com uma mensagem inicial; o e-mail e Instagram também são links diretos.
